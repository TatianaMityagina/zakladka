# 🔖 Закладка

**Помогает помнить сюжет книги — и никогда не спойлерит дальше места, где вы остановились.**

## Проблема

- Отложили книгу на неделю — вернулись и не помните, кто все эти люди и почему они поссорились.
- В длинном романе путаетесь в персонажах: Наташа, Натали и графиня Ростова — это один человек?
- Дочитали — а через месяц помните только общее впечатление (экзамен, книжный клуб, разговор).

Пересказы в интернете — сразу на всю книгу и со спойлерами, есть только для известных книг. ChatGPT по малоизвестным книгам выдумывает, по известным — спойлерит.

## Для кого

Для тех, кто читает с перерывами, читает длинные книги или хочет запомнить прочитанное надолго.

## Что делает ИИ — по тексту вашей книги

| Вкладка | Что делает ИИ |
|---|---|
| **Что было** | Пересказывает главы 1–N: коротко или подробно, с акцентом на последние главы. Плюс «что пока не ясно» — открытые сюжетные линии |
| **Персонажи** | Извлекает героев из каждой главы, склеивает разные имена одного героя, показывает, что о нём известно по главам |
| **Спросить** | Отвечает на вопрос по прочитанному с цитатами; если ответа нет — честно говорит «в прочитанных главах об этом не сказано» |
| **Проверь себя** | Задаёт 4 вопроса по главе, проверяет ответ по смыслу, ошибки сохраняет для повторения |
| **Серия** | Определяет серию и том из файла; предыдущие тома можно подключить — ИИ учтёт их в ответах, пересказе и персонажах |
| **Дневник** | Запись появляется сама, когда двигаете закладку: ИИ пишет, что произошло (можно исправить или переписать), и задаёт вопросы для размышления; вы добавляете мысли и цитаты. Статистика, серия дней, отзыв из ваших записей. Ваши заметки ИИ учитывает в ответах |

### Защита от спойлеров — в архитектуре, а не только в промпте
1. Каждый фрагмент книги привязан к одной главе. Поиск **физически не видит** глав дальше закладки.
2. Разбор главы (пересказ, персонажи) делается только для прочитанных глав.
3. Промпт запрещает модели использовать своё знание книги — модели помнят известные романы наизусть, и одного фильтра поиска мало.

## Технологии

- Backend: Node.js, TypeScript, Express; разбор FB2/EPUB — `node-html-parser`, `jszip`
- Frontend: Vue 3, Vite, TypeScript
- Эмбеддинги: `multilingual-e5-small` локально (transformers.js) — индексация бесплатна и без сети
- Векторы: JSON-кэш + поиск в памяти (гибрид: косинус + совпадение слов — важно для имён)
- LLM: OpenRouter или Anthropic API (переключатель `LLM_PROVIDER`); разбор глав — дешёвая модель, ответы и пересказ — основная

## Архитектура

```
 FB2 / EPUB ──► главы ──► фрагменты ~900 симв. ──► эмбеддинги (локально, кэш)
                 │            (не пересекают главу)            │
                 │                                             ▼
                 │                          поиск: только главы < закладки ──► «Спросить»
                 ▼
        разбор главы LLM (1 раз, кэш): пересказ, события, персонажи
                 │
     ┌───────────┼─────────────────────┐
     ▼           ▼                     ▼
 «Что было»  «Персонажи»          «Проверь себя»
 (разборы    (склейка имён        (вопросы по фрагментам главы →
  1..N)       по главам, код)      проверка ответа → ошибки в повторение)
```

## Как запустить

```bash
npm install
cp .env.example .env   # вписать ключ — см. ниже
npm run dev            # API :3002, UI http://localhost:5174
```

Два провайдера ИИ на выбор:
- **OpenRouter** (по умолчанию): `OPENROUTER_API_KEY` — работает из РФ без VPN, один ключ на разные модели.
- **Anthropic напрямую**: `LLM_PROVIDER=anthropic` и `ANTHROPIC_API_KEY` из console.anthropic.com. Модели: `claude-opus-5-5` для ответов, `claude-haiku-5-5` для разбора глав. Подписка claude.ai для этого не подходит — у API отдельный баланс.

Какой провайдер сейчас работает — видно под кнопками в библиотеке.

Без ключа: `LLM_MODE=mock` — работает разбор книги, поиск и весь UI, без текстов от ИИ.
При первом запуске скачается модель эмбеддингов (~120 МБ).

## Как попробовать

1. http://localhost:5174 → **«Демо: Капитанская дочка»** (общественное достояние, Викитека).
2. «Я прочитала» → глава 3.
3. **Что было** → пересказ трёх глав. **Персонажи** → Гринёв, Савельич, вожатый…
4. **Спросить:** «Кто такой Пугачёв?» — до главы 6 он в книге ещё не назван, ответ не должен его раскрыть.
5. **Проверь себя** → глава 2 → ответьте «не помню» на один вопрос → он попадёт в «Повторить ошибки».
6. Передвиньте закладку на главу 5 → **Дневник**: запись за сегодня. Напишите мысль о Швабрине и добавьте цитату «Береги честь смолоду» (найдётся как «≈ гл. 1»). Затем в **Спросить**: «Что я думала про Швабрина?»

Полный сценарий ручной проверки — [`TEST_CASES.md`](TEST_CASES.md).

Свои книги: FB2, FB2.zip или EPUB (без DRM). Книгу можно удалить из библиотеки (вместе с дневником).

Интерфейс: тёмная тема, адаптив (телефон / планшет / десктоп), анимации — с учётом «уменьшить движение» в системе.
